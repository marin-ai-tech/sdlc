# Возврат на доработку и перехват

`sdlc drop <change> --note "причина"` закрывает ошибочное изменение без слияния delta specs; только человек.

## Чья очередь

- `sdlc next --change <id>` называет следующий шаг и, с ролями, людей, которые могут его сделать.
- `sdlc next --me` — все гейты, которые ждут именно вас, с командами.
- `sdlc roles who <gate> --change <id>` объясняет, кто может утвердить и почему другие не могут.

## Возврат

Человек возвращает изменение на стадию гейта, когда что-то раньше было сделано неверно:

```bash
sdlc rework spec --change add-export --reason missing-requirement --note "Нет случая с пустым именем"
sdlc rework plan --change add-export --reason design-flaw --note "Используйте очередь" --reset
```

После возврата `sdlc next` просит агента изменить артефакты этого гейта. Когда digest изменится,
очередь переходит к человеку для утверждения.

- `--reason` — категория из `rework.reasons`: missing-requirement, wrong-assumption, design-flaw, implementation-bug,
  test-gap, scope-change, other. Аудит их считает, и команда видит, откуда берутся возвраты.
- Утверждения до возврата перестают действовать; последующие гейты ждут новых утверждений.
- `--reset` восстанавливает файлы плана и папку изменения из контрольной точки, записанной при утверждении гейта.
  Отказывает, если файлы изменены или путь идёт через ссылку.
- Агент видит причину и заметку в `sdlc next` и продолжает с этой стадии.
- Повторное утверждение гейта без изменений с утверждения до возврата требует `--note` (почему менять нечего).
- После `rework.max_cycles` возвратов одного гейта (по умолчанию 3) `sdlc next` просит человека перехватить
  изменение или пересмотреть объём, а не запускать агента на новый круг.

## Перехват

Человек забирает изменение у агента, например чтобы аккуратно исправить что-то руками:

```bash
sdlc takeover --change add-export --note "Миграцию поправлю сам"
sdlc release-control --change add-export --note "Миграция исправлена, продолжай"
```

Пока изменение у человека, хук запрещает агенту правки в папке изменения и в файлах плана (без плана — во всём
проекте), а `sdlc next` говорит ждать. При возврате агент читает заметку.

И возврат, и перехват — команды человека: агент предлагает и даёт команду.
