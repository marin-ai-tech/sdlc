# 1. Подготовить проект

Тур идёт по демо «калькулятор»: небольшая команда делает калькулятор для кассы магазина. Алиса — владелец продукта,
Боб — инженер, Кэрол — владелец кода, она делает ревью. Агент пишет артефакты и код, решают люди.

```bash
sdlc init --tools claude,opencode --statusline   # хуки, процессы, субагенты, openspec/sdlc.yaml
sdlc doctor                                      # в порядке ли установка
sdlc help                                        # процессы, команды и решения, которые принимают только люди
sdlc guide                                       # короткие статьи о том, как устроен sdlc
sdlc layout check                                # документы, на которые опираются агенты (AGENTS.md, архитектура, регламент)
```

На что обратить внимание:

- В `openspec/sdlc.yaml` — гейты, кто утверждает каждый, команды проверки и режим принуждения. Файл защищён: агент
  его не меняет, меняет человек.
- `openspec/roles.yaml` (необязательно) называет людей, их роли и правила разделения обязанностей; с ним утверждения
  можно подписывать.
- Хуки видят каждую правку агента. `enforcement.mode: block` запрещает то, что обходит гейт; `warn` только сообщает.

В вашей сессии агент в начале узнаёт, над каким изменением он работает и кто действует дальше. Его всегда можно
спросить «как устроен sdlc?» — он ответит по `sdlc guide`.

Дальше: спланировать работу.
