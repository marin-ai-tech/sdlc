# Полный и облегчённый трек

- **full** — все гейты: intent, spec, plan, verify, review (и release, если он обязателен).
- **lite** — для небольшой ограниченной работы (исправление, документация, мелкая доработка инструментов): изменение
  начинается с плана; intent и spec не применяются.

## Как выбирается трек

1. `sdlc new <имя>` предлагает трек по виду и риску (`--kind bugfix --risk low` предлагает lite). Можно попросить сразу:
   `--track lite`.
2. Человек подтверждает или меняет трек до утверждения плана:

```bash
sdlc track set lite --change fix-rounding --note "Одна функция, покрыта тестами"
sdlc track set full --change fix-rounding --note "Всё-таки затрагивает API платежей"
```

`track set` — решение человека; агент предлагает и даёт команду.

## Что на lite не меняется

План по-прежнему утверждается до кода, доказательства проверки по-прежнему нужны, ревью по-прежнему ждёт владельца
кода. Lite экономит только написание и утверждение intent и spec.

## Когда lite не подходит

Новое поведение, заметное пользователям; всё, что касается безопасности, данных или публичных API; любое изменение
с неясным объёмом — им нужен гейт spec.
