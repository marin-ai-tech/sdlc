# Частые вопросы

**Я написал «утверждаю» в чате. Почему гейт ждёт?**
Ответ в чате не считается утверждением. Выполните `sdlc approve <gate> --change <id>` в своём терминале.

**Можно утвердить через `!sdlc approve …` в чате агента?**
Нет. Команда `!` выполняется в оболочке агента, и CLI откажет.

**Почему гейт устарел?**
После утверждения изменился артефакт, а для review или release — код. Проверьте
`sdlc approve <gate> --change <id> --preview` и утвердите заново.

**Проверка была зелёной, а теперь устарела.**
После `sdlc verify` изменился код. Повторите проверку. Сам коммит её не устаревает.

**Что ждёт меня?**
`sdlc next --me`.

**Кому отдать на ревью?**
`sdlc review suggest --change <id>`.

**Как распределить задачи между агентами?**
Добавьте исполнителя в `openspec/executors.yaml`. Человек выдаёт токен через
`sdlc task executors token <id>`. Задачу назначают через `sdlc board dispatch` или берут через
`sdlc board claim`; результат сдают через `sdlc board submit`. Отказанный результат открывают
через `sdlc board reopen --change <id> --task <n.m> --reason <text>`.

**Как пропустить intent и spec для небольшой правки?**
Человек выбирает облегчённый трек: `sdlc track set lite --change <id>` (`sdlc guide tracks`).

**Агент ошибся на ранней стадии.**
`sdlc rework <gate> --change <id> --reason <категория> --note "…"` (`sdlc guide rework`).

**Хочу исправить сам.**
`sdlc takeover --change <id> --note "…"`; закончив, выполните `sdlc release-control`.

**Хук отказывает.**
Прочтите правило в скобках и `sdlc guide denials`. Человек может временно установить
`enforcement.mode: warn` в `openspec/sdlc.yaml`.

**Всё установлено правильно?**
Проверьте `sdlc doctor`. В Qwen Code при выключенной проверке доверия все папки доверенные.
При включённой доверьте папку проекта: иначе Qwen Code игнорирует `.qwen/settings.json`,
включая хуки и `permissions.deny`.

**Где история решений?**
`sdlc audit --change <id>`, `sdlc log` и `sdlc trace <id>` показывают решения и доказательства.
Аудит сверяет утверждения, возвраты, перехваты, снятия запретов, ответы и ожидания.
Записи CLI содержат `agent` и личность Git в `by`; `sdlc audit --json` считает их в
`agentEvents: { agent, total, byAgent }` отдельно от `agentCommits`.

**Аудитор просит доказательства.**
`sdlc audit --export <папка> [--since <дата>]` выгружает утверждения, подписи,
трейлеры, папки изменений и журнал из openspec/. Список изменений: `sdlc changelog`.

**Сколько кода закоммитили агенты?**
Коммиты из сессии агента получают `SDLC-Agent: <агент>` через установленный git-хук;
`sdlc audit` их считает.

**Я новичок. С чего начать?**
`sdlc guide tour`: семь шагов на примере калькулятора.
