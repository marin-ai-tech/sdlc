# Частые вопросы

**Я написал «утверждаю» в чате. Почему гейт всё ещё ждёт?**
Ответ в чате — никогда не утверждение. Выполните `sdlc approve <gate> --change <id>` в своём терминале.

**Можно утвердить командой `!sdlc approve …` в чате агента?**
Нет: команда с `!` выполняется в оболочке агента, поэтому CLI считает её командой агента и отказывает.

**Гейт пишет «устарело». Что случилось?**
Утверждённый артефакт (а для ревью и релиза — код) изменился после утверждения. Посмотрите
`sdlc approve <gate> --change <id> --preview` и утвердите снова.

**Проверка была зелёной, а теперь устарела.**
Код изменился после `sdlc verify`. Коммит не делает проверку устаревшей, правка кода — делает. Запустите `sdlc verify` снова.

**Что ждёт меня?**
`sdlc next --me`.

**Кому отдать на ревью?**
`sdlc review suggest --change <id>`.

**Как пропустить intent и spec для небольшого исправления?**
Облегчённый трек: `sdlc track set lite --change <id>` (решение человека; `sdlc guide tracks`).

**Агент ошибся на ранней стадии.**
`sdlc rework <gate> --change <id> --reason <категория> --note "…"` (`sdlc guide rework`).

**Хочу исправить сам, чтобы агент не мешал.**
`sdlc takeover --change <id> --note "…"`, а когда закончите — `sdlc release-control`.

**Хук всё время отказывает.**
Посмотрите правило в скобках и `sdlc guide denials`. Чтобы на время смягчить правила процесса, человек может поставить
`enforcement.mode: warn` в `openspec/sdlc.yaml`.

**Всё ли установлено правильно?**
`sdlc doctor`.

**Где история решений?**
`sdlc audit --change <id>`, `sdlc log` и `sdlc trace <id>` — от намерения до доказательств. Аудит ещё сравнивает
решения людей, запланированные треком, с тем, что было (утверждения, возвраты, перехваты, снятия, ответы, ожидания).

**Аудитор просит доказательства.**
`sdlc audit --export <папка> [--since <дата>]`: каждое утверждение со статусом подписи и трейлера, папки изменений и
журнал, ничего вне openspec/. Список изменений выпуска — из спецификаций: `sdlc changelog`.

**Сколько кода закоммитили агенты?**
Коммиты из сессии агента несут `SDLC-Agent: <агент>` (git-хук, который ставит sdlc); `sdlc audit` их считает.

**Я новичок. С чего начать?**
`sdlc guide tour`: семь коротких шагов по демо «калькулятор».
